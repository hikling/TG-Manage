# 功能介绍

TG Manage 的主要入口如下。运行要求和安装方法见 [README](../README.md)。

| 入口 | 功能 |
| --- | --- |
| 仪表盘 | 查看账号概况和当前进程内存占用；容器总内存仍以 `docker stats` 为准。 |
| 账号管理 | 手机验证码或二维码登录；按账号启用 TeleBox、查看状态、设备和代理。 |
| 聊天中心 | 按需开启群组会话，查看与发送消息、附件；关闭时仅读取官方验证码消息。 |
| 系统设置 → 机器人通知 | 仅指定私人 ID 可通过 `/code 账号名` 按需查询 777000 最近 5 分钟的验证码，或通过 `/me` 查看账号名称与备注；空闲时不读取账号消息。 |
| 日志 | 查看应用和各账号 TeleBox 运行日志。 |
| 系统设置 | 管理通用选项、通知和数据备份。 |

TeleBox 每个运行中的账号使用独立进程与会话，插件由 TeleBox 自身管理。历史签到、监听和 AI 任务不会自动执行；升级不会自动清除其持久数据。参见 [无损升级说明](deploy/docker.md#无损升级与回退)。
