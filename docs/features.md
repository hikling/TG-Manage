# 功能介绍

TG Manage 的主要入口如下。运行要求和安装方法见 [README](../README.md)。

| 入口 | 功能 |
| --- | --- |
| 仪表盘 | 展示可自定义封面、账号与 TeleBox 数量、正常账号数量、服务内存和需要关注的账户；可见时每约 30 秒读取已保存的账号检测结果，不触发额外检测。 |
| 账号管理 | 手机验证码或二维码登录；按账号启用 TeleBox、查看状态、设备，以及当前 Xray 线路的 IP 定位。每个健康节点只分配给一个账号，依次使用主订阅、兜底订阅，多出的账号直连；线路检测与账户状态检测分别运行。 |
| 聊天中心 | 按需开启群组会话，查看与发送消息、附件；关闭时仅在授权的 `/code` 请求下读取指定账号的官方验证码消息。 |
| 系统设置 → 机器人通知 | 仅指定私人 ID 可用 `/me` 查看编号、账号名称与备注，再通过 `/code 4` 按需查询第 4 个账号最近 5 分钟的验证码，也支持 `/code 账号名`；重复同一完整指令须间隔 45 秒，不同指令可连续发送，空闲时不读取账号消息。 |
| 零点官方消息报告 | 每天 00:00 检测全部账户及过去 24 小时的官方消息，逐账户汇总账号、当前线路和有无新消息；有消息的账户另推送完整文字与附件。仅定时运行，其他时间不触发完整报告。 |
| 系统设置 | 管理主订阅、兜底订阅、延迟阈值、通知和数据备份；通用设置说明零点自动检测规则，不提供手动保活。 |

TeleBox 每个运行中的账号使用独立进程与会话，插件由 TeleBox 自身管理。面板不缓存每账号进程日志；异常写入脱敏的服务日志。历史签到、监听和 AI 任务不会自动执行；升级不会自动清除其持久数据。参见 [无损升级说明](deploy/docker.md#无损升级与回退)。
