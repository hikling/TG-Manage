# 功能介绍

当前版本提供 Telegram 多账号管理、按需开启的聊天中心、账号工作台、TeleBox 插件和每日任务。运行要求见 [README](../README.md)。

| 模块 | 当前功能 |
| --- | --- |
| 账号管理 | 手机验证码或二维码登录；选择是否启用 TeleBox；账号状态、设备、代理及 Telegram 官方验证码消息。 |
| 聊天中心 | 默认关闭。在系统设置开启后可查看会话和消息、发送文字或附件并显示头像；超过 5 MB 的缓存会清理。关闭时面板普通聊天读取接口拒绝访问。 |
| 账号工作台 | 选择账号和目标对话，立即发送或创建每日定时文字消息。 |
| 任务编排 | 自动读取运行账号已加载的 TeleBox 插件命令，按设置时区每日投递；旧签到动作和关键词监听不运行。 |
| 机器人中心 | Bot Token 接入、资料、命令与主动发送。 |
| 拓展插件 | 保留 TeleBox 原运行时和 TPM；按账号管理独立会话、已加载命令及运行日志。 |
| 系统设置 | 通用、通知、代理、备份与数据管理。 |

旧任务文件不会自动删除，也不会被新任务编排导入执行。升级前请备份完整数据。真实 Telegram 会话和插件执行需在部署环境验证。
