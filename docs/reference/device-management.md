# 设备管理功能

## 概述

设备管理功能允许用户查看和管理 Telegram 账号的已登录设备，提高账号安全性。

## 功能特性

### 1. 设备列表查看

- 查看账号所有已登录设备
- 显示设备型号、平台、IP、位置信息
- 标记当前会话和官方客户端

### 2. 设备下线

- 踢下线非当前会话的设备
- 不能踢下线当前正在使用的会话
- 操作前需要确认

### 3. 每日账户状态检测

- 每日零点的全局状态检测会轻量连接账号会话
- 仅在设置时区的每日 00:00 自动检测全部账户，并与过去 24 小时的官方消息合并推送
- 错过零点后不会在其他时间补启动完整报告；单卡与批量状态检测可在账户管理手动发起
- 原凌晨 3:30 的独立保活任务和设置中的「立即保活」已移除

### 4. 官方消息查看

- 读取 Telegram 官方服务号 777000 的消息
- 查看登录验证码和安全通知
- 只读操作，不会发送消息

### 5. 批量状态检查

- 一键批量检测所有账号状态
- 显示正常/异常数量
- 异常账号显示具体错误信息

## API 接口

### 设备管理

```
GET /api/accounts/{account_name}/devices
DELETE /api/accounts/{account_name}/devices/{auth_hash}
```

### 官方消息

```
GET /api/accounts/{account_name}/official-messages?limit=20
```

账户状态与官方消息报告由配置时区的每日 00:00 定时任务自动运行；账户管理中的单卡和批量状态检测仍可手动执行。

## 配置项

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `device_keepalive_enabled` | `true` | 兼容旧保活配置，不再创建独立自动检测任务 |
| `device_keepalive_interval_days` | `30` | 兼容旧保活间隔（最大 170），不改变固定零点检测时间 |

## 使用场景

1. **安全审计**：定期检查账号登录设备，发现异常设备及时下线
2. **会话维护**：零点检测会连接账号，验证当前会话是否仍有效
3. **验证码获取**：无需打开 Telegram 客户端即可获取登录验证码
4. **批量管理**：多账号场景下快速检查所有账号状态
